# Opiniones de Stream Assistant Beta

Este repositorio público recibe opiniones, reportes de errores y propuestas de mejora. El código de la aplicación permanece en un repositorio privado.

## Enviar una opinión

1. Abre **Opiniones** en la barra lateral de Stream Assistant.
2. Elige **Opinión**, **Error** o **Mejora** y describe lo ocurrido.
3. Pulsa **Abrir en GitHub**, revisa el mensaje y crea la incidencia con tu cuenta de GitHub.

También puedes [crear una incidencia aquí](https://github.com/kanheltw/Stream-Assistant-feedback/issues/new).

Para un error, indica la versión de la app, qué hiciste, qué esperabas y qué pasó. Puedes adjuntar una captura si ayuda. **No publiques tokens, contraseñas, enlaces privados de alertas ni datos personales.**
