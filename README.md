# Stream Assistant Feedback

**Canal público de soporte de Stream Assistant.** Usa este repositorio para informar errores, compartir comentarios o proponer mejoras. El código de la aplicación se mantiene en un repositorio privado.

[Descargar Stream Assistant Beta 1](https://github.com/kanheltw/Stream-Assistant-Releases/releases/tag/v0.5.0-beta.1) · [Ver todas las versiones](https://github.com/kanheltw/Stream-Assistant-Releases/releases)

## Enviar una opinión

1. Abre **Issues** y elige **New issue** (o usa el botón **Opiniones** de la aplicación).
2. Selecciona **Opinión**, **Error** o **Mejora**.
3. Describe lo ocurrido, la versión, los pasos para reproducirlo y el resultado esperado.
4. Revisa el texto y elimina cualquier dato privado antes de publicarlo.

También puedes [crear una incidencia directamente](https://github.com/kanheltw/Stream-Assistant-feedback/issues/new).

> **Privacidad:** no publiques tokens, contraseñas, códigos de autorización, enlaces privados de alertas ni datos personales. Si adjuntas registros o capturas, revísalos antes para retirar información sensible.
